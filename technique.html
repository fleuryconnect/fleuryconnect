Fiche Technique

Découvrez les composants et le fonctionnement de FleuryConnect, un produit prêt à l'emploi.

Composants Électroniques

🔌 Arduino Nano

Microcontrôleur principal - Cœur du système qui gère toutes les opérations : lecture des capteurs, affichage LCD, contrôle des LED.

  • Processeur : ATmega328P
  • Tension : 5V
  • 14 broches digitales I/O
  • 8 broches analogiques

💧 Capteur d'Humidité

Capteur capacitif - Mesure la teneur en eau du sol sans contact direct avec les racines, préservant ainsi la santé de la plante.

  • Type : Capacitif (FC-28 ou équivalent)
  • Tension : 3.3V - 5V
  • Sortie : Analogique (0-1023)
  • Précision : Adaptable par calibration

🖥️ Écran LCD

Affichage 16x2 - Affiche l'heure en temps réel et peut également montrer le niveau d'humidité sur demande.

  • Type : LCD 16x2 avec rétroéclairage
  • Interface : I2C (communication optimisée)
  • Contraste : Réglable
  • Consommation : Faible

🔴 LED d'Alerte

Indicateur visuel - LED rouge qui s'allume lorsque l'humidité est insuffisante, attirant l'attention de manière discrète mais efficace.

  • Couleur : Rouge (haute visibilité)
  • Tension : 5V
  • Résistance : 220Ω (protection)
  • Mode : Clignotant ou fixe

Algorithme d'Alerte

Logique de Fonctionnement

Le système utilise un algorithme intelligent qui analyse les variations d'humidité pour déterminer quand une alerte est nécessaire.

Fonctionnement du système :

FleuryConnect fonctionne de manière autonome. Le système lit en continu le niveau d'humidité du sol via le capteur intégré. Si l'humidité descend sous le seuil critique (30% par défaut), la LED d'alerte s'allume automatiquement pour vous rappeler d'arroser vos plantes. L'écran LCD affiche l'heure en temps réel, faisant de FleuryConnect un objet utile au quotidien.

Fonctionnalités Avancées

  • Filtrage des valeurs : Moyenne glissante pour éviter les faux positifs dus aux variations momentanées
  • Hystérésis : Seuil différent pour l'activation et la désactivation de l'alerte (évite le clignotement)
  • Calibration : Possibilité d'ajuster le seuil selon le type de plante
  • Mode économie : Réduction de la fréquence de lecture en mode normal

Spécifications Techniques
